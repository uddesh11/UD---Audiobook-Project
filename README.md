# UD---Audiobook-Project
# Audiobook Generator using Python

This project converts text into speech (audiobook) using Python.

## Features:
- Convert text file into audio (MP3)
- Supports multiple languages
- Easy to use and beginner-friendly

## Technologies Used:
- Python
- gTTS (Google Text-to-Speech)

## How to Run:
1. Install gTTS: pip install gtts
2. Run main.py
3. Output file: audiobook.mp3

## Future Improvements:
- Add voice selection
- Add background music
